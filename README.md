# Fat Loss Meal Planner

A static meal-planning page for creating, saving, and comparing simple fat-loss recipes.

## Features

- Create and save daily recipes in the browser
- Search foods while editing a recipe
- Calculate calories, protein, carbs, and fat
- Show macro calorie ratio
- Browse and search a built-in food nutrition table
- Export and import recipe JSON backups

## Deploy

This project is a static site. The public assets live in `web/`.

```powershell
wrangler pages deploy "D:\project\减肥餐计划\web" --project-name fat-loss-meal-planner
```
